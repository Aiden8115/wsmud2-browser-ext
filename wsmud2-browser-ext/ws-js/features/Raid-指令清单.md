# Raid.js 指令处理器清单（v26.3.3 对照版）

> 本文档是 `ws-js/features/Raid.js`（6928 行）的"命令地图"，供后续改动快速定位。
> 结构：流程脚本源码 → **预编译器**（展开旧语法/子流程/守卫）→ **编译器**（生成指令序列）
> → **指令执行器**（`CmdExecuteCenter` 按优先级匹配执行）。所有命令注册处都带行号。

---

## 一、源码预处理（Precompiler，L174-190）

| 规则 | 匹配 | 作用 | 位置 |
|---|---|---|---|
| 行注释 | `//` 开头行 | 删除 | L392-403 |
| 块注释 | `/* ... */` | 删除 | L405-426 |
| 子流程 | `<===` ... `===>` 之间 | 折叠为一条 `<===...===>` 指令（执行时开子流程） | L432-461 |
| 守卫块 | `<---` ... `--->` | 折叠为 `%guardStart/%guardEnd`（守卫失败整块跳过） | L467-520 |
| 调用 | `@call 名 [参数]` | 展开为 `[if] true` + 目标源码 | L523-568 |
| 空行 | 空白行 | 删除 | L573-586 |
| Raid 1.x 兼容 | 见下 | 旧语法翻译成新语法 | L590-704 |

**Raid 1.x 兼容翻译（L590-704）**
- `#[...]` → `<---  [...]  --->`（旧守卫）
- `[...]` 条件行 → `[if] 条件`（`&`→`&&`、`|`→`||`、`=`→`==` 自动补全）
- `[=条件]命令` → `@until 条件` + 命令
- `@next` → `[continue]`；`@exit` → `[break]`

## 二、编译器指令（编译期生成，Compiler L192-372 / Compile Executor L1187-1278）

| 指令 | 作用 |
|---|---|
| `[if] 条件` / `[while] 条件` / `[exit]` / `[continue]` / `[break]` | 流程控制（缩进层级 = 块结构） |
| `%exit` | 立即停止整个流程（L1190-1198） |
| `%pass` | 空操作（L1200-1207） |
| `%PC=表达式` / `%PC=CCxxx` | 设置程序计数器（跳转）（L1209-1229） |
| `%CC=断言名` | 把断言结果存入 `_cc`（L1231-1242） |
| `%guardStart` / `%guardEnd` | 守卫块边界（L1244-1264） |
| `<===源码===>` | 启动子流程（L1266-1278） |
| `($变量) = 表达式` | 变量赋值：大写开头=持久变量(`global_params@角色ID`)，小写=临时变量（L1284-1317） |
| `{r名字}` / `{b名字}` / `{物品?}` | 占位符解析（房间 NPC/背包物品/可空物品，由 CmdPrehandleCenter 处理） |

## 五、变量系统（VariableStore，L1319-1390 等）

- **预设变量**（冒号开头，只读）：`:date :day :hour :minute :second :mSec`（L1564-1573）、
  `:hp :maxHp :mp :maxMp :state :room :living :free :exist :gains ...`（Role/Room 提供）、
  **`:idle`（是否发呆且不在战斗）/ `:idle_time`（该状态连续秒数，26.2.3 新增）**
- **流程变量**：`($v)` 大写 = 持久变量（存 `global_params@角色ID`），小写 = 临时变量
- **条件断言**：`(:free) == true`、`(:room 副本区域,忧愁谷)==true`、`(SDYTjlsx) == 0` 等，支持 `&& || == != < >`、`null/undefined`
- **发呆计时**：`(:idle_time)` 离开发呆/进入战斗自动归 0；开始挂机（挖矿/修炼/钓鱼）自动重置；
  也可在流程/触发中用 `@js Role.resetIdleTime()` 手动重置

## 六、其他全局对象（供流程/外部调用）

- `ToRaid.perform(源码, 名称)` —— 万能执行入口（游戏内 `//` 命令、`@` 命令、外部脚本都走它）
- `Role` —— 角色状态（findItem / renew / cleanBag / gains / coolingSkills / isFree 等）
- `DungeonsShortcuts`（L5653+）—— 一键咸鱼扫荡妖塔等内置快捷
- `ManagedPerformerCenter` —— 流程管理（start/stop/getAll）
- `Server`（L3808+）—— 云端分享流程/触发器（uploadFlows/downloadFlows/importFlow 等）
