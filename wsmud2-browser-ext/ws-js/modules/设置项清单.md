# 设置项清单（v26.3.3 对照版）

> 本文档是插件的"设置字典"：默认值在 `ws-js/modules/config-vars.js`，
> 登录时从 localStorage 读回用户值在 `global-init.js` 的 `GlobalInit.configInit()`（L1089 起），
> 保存时经 `GM_setValue` 写 localStorage。想改默认设置 → 改 config-vars.js 里对应变量即可。

---

## 全局设置（存储键直接是键名，所有角色共享）

| 设置 | 默认值 | 说明 |
|---|---|---|
| `_shieldswitch` | `'关'` | 聊天屏蔽总开关 |
| `_shield` | `''` | 屏蔽人物名 |
| `_shieldkey` | `''` | 屏蔽关键字 |
| `_pushSwitch` / `_pushType` / `_pushToken` | `'关'` / `'0'` / `''` | 远程推送开关 / 渠道 / Token |

| `_auto_relogin`（备用） | — | 见角色级 auto_relogin |

## 其它内部键（不建议手动改）

| 键 | 说明 |
|---|---|

## 设置面板位置速查（ui.js）

| 分组 | 位置 | 主要项 |
|---|---|---|
| 挂机/自动 | syssetting 前半 | autowork、auto_pfmswitch、unauto_pfm、automarry、autoBoss 等 |
| 屏蔽选项 | L247 附近 | shieldswitch/shield/shieldkey |
| 推送配置 | L252 附近 | pushSwitch/pushType/pushToken + 「测试推送」按钮 |
| 技能自定义 | L271 附近 | zdyskills/zdyskilllist |
| 自定义按钮 | L276 附近 | zdy_btnlist |
| 系统 | L278 附近 | 上传/下载配置、孤儿键扫描等 |
