## 一、这个扩展是干什么的？

它是一套给网页游戏《武神传说》（wsmud2.com）用的**外挂辅助工具**，功能包括：

- **自动战斗**：自动打怪、自动放技能、自动疗伤打坐、自动比试
- **自动任务**：自动挖矿、修炼、钓鱼、定时任务、状态监控
- **Raid 脚本引擎**：在游戏里输入 `/` 开头的命令（如 `kill 木头人`），执行一段段自动流程
- **触发器**：设定"某事件发生时自动做某件事"（比如血少了自动吃药）
- **界面增强**：右键传送菜单、快捷键、技能 CD 倒计时、自定义快捷栏、综合工具网页版等
- **一键登录**：记住账号密码，自动登录进游戏

它本质上是一堆 **JavaScript 脚本**，被塞进游戏页面里运行，通过拦截游戏的网络消息来实现上面这些功能。

## 二、怎么把它加载到浏览器（Chrome）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角的 **「开发者模式」** 开关
3. 点左上角 **「加载已解压的扩展程序」**
4. 选择本文件夹：`D:\DS\WSMUD\ext-26.1`
5. 打开游戏网站 `wsmud2.com`，进游戏就能看到效果

**以后每次改完代码**：回到 `chrome://extensions`，点这个插件卡片上的 **刷新按钮（🔄）**，然后 **刷新游戏页面**，改动才会生效。

## 四、扩展是怎么工作的？（通俗版流程图）

```
游戏网页打开
   │
   ▼
content.js 按顺序把 30 多个脚本塞进页面
   │  （顺序很关键：地基 → 模块 → 功能，不能乱）
   ▼
websocket-proxy.js 劫持 WebSocket
   │  （游戏服务器发来的每条消息，先给插件"看一眼"）
   ▼
消息分发给各模块：
   ├─ ws.js 画地图、显示房间、处理登录
   ├─ global-init.js 更新 GameState 全局状态、触发自动功能
   ├─ wg-combat.js 根据状态决定自动出招/疗伤
   ├─ Raid.js 执行你输入的 / 命令流程
   └─ Trigger.js 检查条件是否满足，满足就执行触发器动作
   │
   ▼
玩家操作（点按钮/按快捷键/输入命令）
   │
   ▼
send_cmd → WebSocket 发回服务器
```

**一句话总结**：插件"蹲在"游戏和服务器之间，看得到所有消息，也能冒充你发命令。

## 六、改代码的 3 条保命规则

1. **改之前先备份**：把要改的文件复制一份（改名成 `xxx.js.bak`），改坏了能还原。
2. **一次只改一个点**：改完 → 刷新插件（chrome://extensions 点 🔄）→ 刷新游戏页 → 测试。没问题再改下一个。
3. **JSON 文件（manifest.json）里我加了注释**，需要 Chrome 116 以上版本（2023 年后安装的 Chrome 都满足）。如果哪天 Chrome 报"清单文件解析失败"，把 manifest.json 里的 `//` 开头的行删掉即可。
